# FarmCargo

Powering the Supply Chain of Life.

사료·곡물·퇴비 등 농업 화물 배차 앱(운수사용)입니다.

## 저장소 구성

| 경로 | 설명 |
|---|---|
| `app/` | Flutter 앱(현재 Android만). **Android Studio에서는 이 폴더를 열어야 합니다.** |
| `farm-cargo-mockups.html` | 화면 목업(기획 참고용) |
| `app-demo.html` | 클릭 가능한 HTML 데모 |
| `index.html`, `manifest.json`, `sw.js`, `icon-*.png` | 목업/데모를 PWA로 배포하기 위한 파일 |

앱 개발 환경 설정과 실행 방법은 [`app/README.md`](app/README.md)를 참고하세요.
