# 팜카고 규칙 진입 안내

수정일: 2026-11-03

공통 작업 규칙은 저장소 루트의 [AGENTS.md](../AGENTS.md) 하나로 관리한다. 작업 전에 해당 파일을 읽는다. 이 파일에 공통 규칙을 중복 작성하지 않는다.

- 현재 방침: **웹 형식으로만 개발, Flutter 앱·Flutter Web 개발은 명시적인 재개 지시 전까지 보류**.
- [현재 요구사항](docs/requirements.md)을 읽고, 작업에 따라 [DB](docs/rules/database.md)·[프론트엔드](docs/rules/frontend.md)·[백엔드](docs/rules/backend.md) 규칙을 추가로 읽는다.
- 이 파일의 문구와 최신 사용자 지시가 다르면 사용자 지시를 기준으로 관련 문서를 갱신한다.
